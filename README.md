🎓 Horizon University Portal
Empowering Academic Management through Full-Stack Excellence
Welcome to the Horizon University Portal, a sophisticated, full-stack solution designed to streamline student administration and attendance tracking. Built with a focus on clean architecture and modern UI/UX, this project serves as a bridge between robust Java backend services and a high-end, responsive frontend.

🌟 Key Features
Centralized Student Management: Full CRUD (Create, Read, Update, Delete) capabilities for student records.

Dynamic Attendance System: Real-time presence marking integrated directly with the database.

Premium "Glassmorphism" UI: A modern landing page featuring frosted glass effects, high-fidelity typography (Montserrat), and intuitive navigation.

RESTful Architecture: Seamless communication between the frontend and backend using the JavaScript Fetch API.

Data Integrity: Implemented relational database constraints to ensure academic records remain consistent and reliable.
